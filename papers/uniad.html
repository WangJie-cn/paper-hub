🎯 UniAD: Planning-oriented Autonomous Driving

arxiv: 2212.10156 | 作者: 上海AI Lab + 香港大学 | 年份: 2023 (CVPR Best Paper)

一句话总结

将自动驾驶的 感知、预测、规划 统一到一个端到端框架，以 规划为导向 设计整个系统。

核心贡献

  1. 统一框架 — 检测、跟踪、地图、预测、规划一体化
  2. Query-based 设计 — 用 query 串联所有模块
  3. Planning-oriented — 优化目标直指最终规划
  4. CVPR 2023 Best Paper

核心设计

1. Agent Query

# 每个交通参与者用一个 query 表示
# 这个 query 贯穿整个流程

Q_agent → Detection → Tracking → Prediction → Planning
           "检测"     "跟踪"      "预测轨迹"   "规划避让"

2. 模块间信息流

  • Track → Motion: 跟踪结果告诉预测模块"跟踪谁"
  • Map → Motion: 地图告诉预测"在哪条路上"
  • Motion → Planning: 预测结果告诉规划"怎么避让"

3. 联合训练

L_total = λ₁L_detect + λ₂L_track + λ₃L_map 
        + λ₄L_motion + λ₅L_occ + λ₆L_plan

关键洞察

为什么要统一？

  1. 避免误差累积 — 独立模块的错误会传递
  2. 信息共享 — 感知和规划可以互相帮助
  3. 端到端优化 — 直接优化最终目标

为什么以规划为导向？

感知不是目的，安全行驶才是。不需要检测所有物体，只需要检测影响规划的物体。

个人思考

UniAD 最重要的贡献不是某个具体模块，而是 **统一思想**。它证明了端到端比模块化更强。这对自动驾驶的未来有深远影响：也许我们不需要精心设计每个模块的接口，只需要一个大模型从传感器直接输出轨迹。
