🎮 LMDrive: Closed-Loop End-to-End Driving with LLMs

arxiv: 2312.07488 | 作者: 香港科技大学 + 商汤 | 年份: 2024

一句话总结

用 LLM 做 闭环端到端驾驶：接收自然语言指令 + 传感器输入，直接输出控制信号，在 CARLA 仿真器中实时运行。

核心贡献

  1. 闭环驾驶 — 在仿真器中实时运行，不只是离线评估
  2. 语言指令 — 接受自然语言导航指令（"下个路口左转"）
  3. 端到端 — 传感器 → LLM → 控制信号
  4. 多传感器融合 — 相机 + LiDAR + 导航指令

优势

为什么用 LLM？

  1. 泛化能力 — 理解新的语言指令
  2. 常识推理 — "红灯要停" 不需要显式学习
  3. 可解释性 — 可以生成解释文本

vs 传统端到端

传统 E2E LMDrive
输入 传感器 传感器 + 语言
推理 黑盒 CNN LLM (可解释)
泛化 有限 更强

局限性

  • 延迟 — LLM 推理比 CNN 慢
  • 仿真 Gap — CARLA → 真实世界
  • 长尾场景 — 罕见情况可能失败

个人思考

LMDrive 展示了 LLM 驾驶的可能性。但我更关心延迟问题——自动驾驶需要实时响应，而 LLM 推理可能需要几百毫秒。也许未来需要小型专用模型，而不是通用 LLM。
