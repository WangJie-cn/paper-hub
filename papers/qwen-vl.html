🌐 Qwen-VL: A Versatile Vision-Language Model

arxiv: 2308.12966 | 作者: 阿里巴巴通义实验室 | 年份: 2023

一句话总结

阿里的多模态大模型，支持 中英双语、多图输入、高分辨率 OCR，在中文场景表现尤其强。

核心贡献

  1. 细粒度视觉理解 — 支持 bbox 输入/输出（Grounding）
  2. 多图多轮对话 — 同时理解多张图片
  3. 高分辨率处理 — 动态分辨率，适合 OCR
  4. 中英双语 — 国内首个强力开源 VLM

模型架构

┌─────────────────────────────────────────┐
│  Image(s) + Bounding Boxes (可选)       │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Vision Encoder: ViT-bigG (1.9B)        │
│  + Position-aware Adapter               │
│  输出: 256 visual tokens per image      │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Single-layer Cross-attention           │
│  (压缩 visual tokens)                   │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Qwen-7B / Qwen-14B LLM                 │
│  [图像tokens] [文本tokens]              │
└─────────────────────────────────────────┘

特色功能

1. Grounding（定位）

# 输入带 bbox
User: <img>picture.jpg</img> 描述 <box>(120,80),(450,320)</box> 区域

# 输出带 bbox
Assistant: 这是一只橙色的猫 <box>(120,80),(450,320)</box>

2. 多图理解

User: <img>img1.jpg</img> <img>img2.jpg</img>
这两张图有什么区别？
