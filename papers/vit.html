🖼️ ViT: An Image is Worth 16x16 Words

arxiv: 2010.11929 | 作者: Alexey Dosovitskiy 等 (Google) | 年份: 2020

一句话总结

把图像切成 16×16 的 patch，当作 NLP 的 token 序列输入标准 Transformer，抛弃 CNN 也能在图像分类上取得 SOTA。

核心贡献

  1. 纯 Transformer 架构 — 完全不用卷积
  2. Patch Embedding — 图像 → 序列的桥梁
  3. 规模定律验证 — 数据越多，ViT 越强
  4. 开创视觉 Transformer 时代

模型架构

输入图像 (224×224×3)
        │
        ▼
┌───────────────────┐
│   Patch Embedding │  将图像切成 14×14 = 196 个 patch
│   (16×16 patches) │  每个 patch: 16×16×3 = 768 维
└─────────┬─────────┘
          │
          ▼
    + Position Embedding  (可学习的位置编码)
    + [CLS] Token         (用于分类)
          │
          ▼
┌───────────────────┐
│   Transformer     │  12/24 层 Multi-Head Attention
│     Encoder       │  + MLP + LayerNorm
└─────────┬─────────┘
          │
          ▼
     [CLS] output
          │
          ▼
    Classification Head → 类别预测

核心公式

Patch Embedding

# 输入: x ∈ R^(H×W×C)
# 切成 N = HW/P² 个 patch，每个 patch 展平后投影

z₀ = [x_class; x¹_pE; x²_pE; ...; xᴺ_pE] + E_pos

# x_class: [CLS] token
# E: patch 投影矩阵 (P²C × D)
# E_pos: 位置编码 (N+1 × D)

Transformer Encoder

# L 层 Transformer
for l in range(L):
    z'_l = MSA(LN(z_{l-1})) + z_{l-1}   # Multi-Head Self-Attention
    z_l  = MLP(LN(z'_l)) + z'_l          # Feed-Forward

y = LN(z_L[0])  # 取 [CLS] token 输出

关键发现

1. 数据规模是关键

  • ImageNet (1M) 上训练 → 不如 ResNet
  • ImageNet-21K (14M) 上预训练 → 持平
  • JFT-300M (300M) 上预训练 → 超越 ResNet
ViT 需要大规模数据！CNN 的归纳偏置（局部性、平移不变性）在小数据时有优势。

2. 位置编码学到了什么？

可视化发现：相邻 patch 的位置编码相似，模型自己学会了 2D 结构。

3. Attention 可视化

浅层：局部注意力（类似卷积）
深层：全局注意力（看整张图）

与 CNN 对比

CNN (ResNet) ViT
归纳偏置 局部性、平移不变性 几乎没有
感受野 逐层扩大 第一层就是全局
小数据 更好 较差
大数据 饱和 持续提升
计算效率 局部计算 O(N²) 全局注意力

代码示例

import torch
from transformers import ViTModel, ViTImageProcessor
from PIL import Image

# 加载模型
processor = ViTImageProcessor.from_pretrained('google/vit-base-patch16-224')
model = ViTModel.from_pretrained('google/vit-base-patch16-224')

# 处理图像
image = Image.open("cat.jpg")
inputs = processor(images=image, return_tensors="pt")

# 前向传播
outputs = model(**inputs)
last_hidden_state = outputs.last_hidden_state  # (1, 197, 768)
cls_token = outputs.pooler_output              # (1, 768)

print(f"Patch tokens: {last_hidden_state.shape}")
print(f"CLS token: {cls_token.shape}")

个人思考

ViT 证明了 Transformer 的通用性——不需要针对视觉任务设计特殊架构，直接复用 NLP 的 Transformer 就能 work。代价是需要更多数据，但在大模型时代，数据不是问题。
