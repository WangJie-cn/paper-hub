📎 CLIP: Learning Transferable Visual Models From Natural Language Supervision

arxiv: 2103.00020 | 作者: Alec Radford 等 (OpenAI) | 年份: 2021

一句话总结

用 4 亿图文对训练，让图像和文本在同一个嵌入空间对齐，实现了史无前例的 zero-shot 图像分类能力。

核心贡献

  1. 对比学习框架 — 图像编码器 + 文本编码器，通过对比损失对齐
  2. 大规模预训练 — 4 亿网络图文对 (WIT-400M)
  3. Zero-shot Transfer — 不微调直接迁移到 30+ 数据集
  4. 自然语言监督 — 用文本描述代替离散类别标签

模型架构

┌─────────────┐     ┌─────────────┐
│   Image     │     │    Text     │
│  Encoder    │     │   Encoder   │
│ (ViT/ResNet)│     │(Transformer)│
└──────┬──────┘     └──────┬──────┘
       │                   │
       ▼                   ▼
   [I₁,I₂,...,Iₙ]     [T₁,T₂,...,Tₙ]
       │                   │
       └───────┬───────────┘
               ▼
        Cosine Similarity
         (n × n matrix)
               ▼
       Contrastive Loss

图像编码器

  • ResNet-50/101 — 经典 CNN
  • ViT-B/16, ViT-L/14 — Vision Transformer（性能更好）

文本编码器

  • 12 层 Transformer
  • 最大 77 tokens
  • 取 [EOS] token 的特征作为文本表示

核心公式

InfoNCE Loss（对比损失）

# 对于 batch 中的图文对 (I_i, T_i)
# 正样本：对角线 (I_i, T_i) 应该相似
# 负样本：非对角线 (I_i, T_j) 应该不相似

L = -1/N * Σ[ log(exp(sim(I_i,T_i)/τ) / Σⱼexp(sim(I_i,T_j)/τ)) ]

# τ 是可学习的温度参数

Zero-shot 分类

# 将类别名转换为文本 prompt
prompts = ["a photo of a {class}" for class in classes]

# 计算图像与所有 prompt 的相似度
similarities = image_features @ text_features.T

# 取相似度最高的类别
prediction = argmax(similarities)

关键洞察

为什么有效？

  1. 规模效应 — 4 亿数据 >> ImageNet 的 1.2M
  2. 自然语言监督 — 文本描述比类别标签信息丰富
  3. 对比学习 — batch 内负样本足够多

Prompt Engineering

不同 prompt 影响很大：

  • "a photo of a dog" ✓ 更好
  • "dog" ✗ 太简单
  • "a photo of a {class}, a type of pet" ✓ 增加上下文

代码示例

import torch
import clip
from PIL import Image

# 加载模型
device = "cuda"
model, preprocess = clip.load("ViT-B/32", device=device)

# 准备图像和文本
image = preprocess(Image.open("cat.jpg")).unsqueeze(0).to(device)
text = clip.tokenize(["a cat", "a dog", "a bird"]).to(device)

# 计算特征
with torch.no_grad():
    image_features = model.encode_image(image)
    text_features = model.encode_text(text)
    
    # 归一化 + 相似度
    image_features /= image_features.norm(dim=-1, keepdim=True)
    text_features /= text_features.norm(dim=-1, keepdim=True)
    similarity = (image_features @ text_features.T).softmax(dim=-1)
    
print(similarity)  # tensor([[0.95, 0.03, 0.02]])

个人思考

CLIP 的核心洞察：语言是更好的监督信号。类别标签是离散的、有限的；而自然语言描述是连续的、开放的。这让模型学到的不仅是"这是狗"，而是"毛茸茸的、可爱的、四条腿的动物"。
