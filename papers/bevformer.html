🦅 BEVFormer: Learning Bird's-Eye-View Representation

arxiv: 2203.17270 | 作者: Zhiqi Li 等 (南京大学 + 上海AI Lab) | 年份: 2022

一句话总结

用 Transformer 将多视角相机图像融合到统一的 鸟瞰图 (BEV) 空间，实现纯视觉的 3D 目标检测和地图分割。

核心贡献

  1. BEV Query — 用可学习的 query 表示 BEV 空间
  2. Spatial Cross-Attention — 从多视角图像采样特征
  3. Temporal Self-Attention — 融合历史 BEV 特征
  4. 端到端训练 — 无需深度估计预处理

BEV 优势

  • 统一坐标系 — 所有视角融合到同一空间
  • 便于下游任务 — 规划、预测都在 BEV 空间进行
  • 避免遮挡歧义 — 3D 位置明确

核心机制

1. BEV Queries

# 可学习的 BEV query 网格
Q_bev ∈ R^(H × W × C)

# H, W: BEV 网格大小 (如 200×200)
# C: 特征维度 (256)
# 每个 query 对应 BEV 空间中的一个位置

2. Spatial Cross-Attention

# 核心思想：BEV query 去图像特征中"采样"

for each BEV query Q at position (x, y):
    # 在 z 轴上采样多个高度
    for z in [z_1, z_2, ..., z_n]:
        # 3D 点 (x, y, z) 投影到各相机
        for cam in cameras:
            (u, v) = project_3d_to_2d((x, y, z), cam)
            # 从图像特征采样
            f = bilinear_sample(F_cam, u, v)
        
    # 加权聚合
    Q_updated = Attention(Q, sampled_features)

3. Temporal Self-Attention

# 融合历史 BEV 特征
B_t = TemporalAttention(Q_t, B_{t-1})

# 关键：需要对齐！
# 根据自车运动将历史 BEV 变换到当前坐标系
B'_{t-1} = warp(B_{t-1}, ego_motion)

Deformable Attention

BEVFormer 使用 Deformable Attention 提高效率：

# 标准 Attention: 所有位置
Attention(Q, K, V) = softmax(QK^T)V  # O(N²)

# Deformable Attention: 只采样 K 个参考点
DeformAttn(Q, p, F) = Σ_k A_k · F(p + Δp_k)  # O(NK)

# Δp_k: 可学习的偏移
# A_k: 可学习的权重

个人思考

BEVFormer 的关键洞察：不要显式估计深度，让模型自己学。通过 Spatial Cross-Attention 在多个高度采样，模型隐式学会了哪些高度最相关。这比 LSS 的显式深度估计更鲁棒。时序融合也很精彩——自动驾驶的时序一致性很重要。
