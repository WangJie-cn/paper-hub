🧠 Backbone/Task Head vs Multi-Head Attention

1️⃣ 模型架构级别：Backbone + Task Heads

  • Backbone：特征提取器，处理原始输入，输出通用特征表示
  • Task Head：任务特定的输出层，每个 Head 负责一个下游任务
  • 多个 Task Heads 共享 同一个 Backbone 的特征

2️⃣ Transformer 内部：Multi-Head Attention

  • Multi-Head：将 Q/K/V 分成多组，并行计算注意力
  • 每个 Head 学习 不同的注意力模式（有的关注局部，有的关注全局）
  • 最后 Concat + Linear 融合所有 Head 的输出

3️⃣ 核心区别

概念层级目的数量
Backbone模型架构特征提取通常 1 个
Task Head模型架构任务输出按任务数量
Attention HeadTransformer 层内多角度注意力8/16/32...

4️⃣ 它们的联系

ViT Backbone

内部使用 Multi-Head Attention 来建模图像 patch 之间的关系

DETR Detection Head

内部也有 Transformer，使用 Multi-Head Attention 做目标查询

👉 Multi-Head Attention 是更底层的组件，可以出现在 Backbone 或 Task Head 中
