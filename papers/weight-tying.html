🔗 权重共享 (Weight Tying)

1️⃣ 什么是权重共享？

在 LLM 中，wte（输入 embedding）和 lm_head（输出层）使用同一个权重矩阵。

token_id: 3 ("界")
↓
wte: 查表 → embedding
↓
Transformer (N层)
↓
hidden_state
↓
lm_head: hidden × WT


🔗 橙色框共享同一个权重矩阵 W

2️⃣ 两层做的事情

层输入→输出操作
wte token_id → 向量 查表取第i行
lm_head hidden → logits hidden × WT

3️⃣ 具体例子

词表: [你, 好, 世, 界]，vocab_size=4, n_embd=3

wte 权重矩阵 W (4×3):

你 [ 0.1, 0.2, 0.3 ] 好 [ 0.4, 0.5, 0.6 ] 世 [ 0.7, 0.8, 0.9 ] 界 [ 1.0, 1.1, 1.2 ]

输入阶段 (wte):

输入 "界" (id=3)
→ 查表取第3行
→ [1.0, 1.1, 1.2]

输出阶段 (lm_head):

hidden_state = [0.5, 0.8, 0.3]

logits = hidden × WT

→ 点积结果 = hidden 和每个词 embedding 的相似度

4️⃣ 为什么有效？

wte: token_id → 语义空间的点

lm_head: 语义空间的点 → 和每个词的相似度


共享权重意味着：

• 输入 "猫" 得到向量 v_猫

• 输出时，hidden 和 v_猫 越接近，预测 "猫" 概率越高


💡 如果模型"想说猫"，它的 hidden 就应该接近 "猫" 的 embedding

5️⃣ 节省多少参数？

# 不共享

wte: 50000×768 = 38.4M

lm_head: 768×50000 = 38.4M

总共: 76.8M


# 共享

只有 38.4M，节省 50%!

6️⃣ 代码实现

# nanoGPT model.py self.wte = nn.Embedding(vocab_size, n_embd) self.lm_head = nn.Linear(n_embd, vocab_size) # 关键：权重共享 self.wte.weight = self.lm_head.weight
