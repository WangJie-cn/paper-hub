🔗 权重共享 (Weight Tying)

1️⃣ 什么是权重共享？

在 LLM 中，wte（输入 embedding）和 lm_head（输出层）使用同一个权重矩阵。

token_id: 3 ("界")

↓
wte: 查表取第3行 → [1.0, 1.1, 1.2]

↓
Transformer Backbone (N层)

↓
hidden_state: [0.5, 0.8, 0.3]

↓
lm_head: hidden × WT → logits


🔗 橙色框共享同一个权重矩阵 W

2️⃣ 两层做的事情

层输入输出操作
wte token_id (整数) embedding 向量 查表：取矩阵的第 i 行
lm_head hidden_state 向量 logits (vocab_size 维) 矩阵乘法：hidden × WT

3️⃣ 具体例子

词表: [你, 好, 世, 界] vocab_size=4, n_embd=3 wte 权重矩阵 W (4×3): dim0 dim1 dim2 你 [ 0.1, 0.2, 0.3 ] 好 [ 0.4, 0.5, 0.6 ] 世 [ 0.7, 0.8, 0.9 ] 界 [ 1.0, 1.1, 1.2 ] 输入阶段 (wte): 输入 "界" (id=3) → 查表取第3行 → [1.0, 1.1, 1.2] 输出阶段 (lm_head): hidden_state = [0.5, 0.8, 0.3] ← Backbone 输出 logits = hidden × WT = [0.5, 0.8, 0.3] × [[0.1, 0.4, 0.7, 1.0], [0.2, 0.5, 0.8, 1.1], [0.3, 0.6, 0.9, 1.2]] → 点积结果就是 hidden 和每个词 embedding 的相似度！

4️⃣ 为什么有效？

wte 做的事: token_id → 语义空间的点 lm_head 做的事: 语义空间的点 → 和每个词的相似度 (点积) 共享权重意味着： • 输入 "猫" 得到向量 v_猫 • 输出时，hidden_state 和 v_猫 越接近，预测 "猫" 的概率越高 💡 如果模型"想说猫"，它的 hidden_state 就应该接近 "猫" 的 embedding

5️⃣ 节省多少参数？

# 不共享：两套参数
wte = nn.Embedding(50000, 768)    # 50000×768 = 38.4M
lm_head = nn.Linear(768, 50000)   # 768×50000 = 38.4M
# 总共 76.8M 参数

# 共享：一套参数
wte.weight = lm_head.weight       # 只有 38.4M 参数
# 节省 50%！

6️⃣ nanoGPT 中的实现

# nanoGPT model.py
class GPT(nn.Module):
    def __init__(self, config):
        self.transformer = nn.ModuleDict(dict(
            wte = nn.Embedding(vocab_size, n_embd),
            ...
        ))
        self.lm_head = nn.Linear(n_embd, vocab_size, bias=False)
        
        # 关键：权重共享
        self.transformer.wte.weight = self.lm_head.weight

这是 GPT-2 论文中的技巧，现已成为 LLM 标配 ✨
