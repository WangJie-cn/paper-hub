🦙 LLaVA: Visual Instruction Tuning

arxiv: 2304.08485 | 作者: Haotian Liu 等 (UW-Madison + Microsoft) | 年份: 2023

一句话总结

用 GPT-4 生成 视觉指令数据，训练一个能看图聊天的开源多模态大模型，简单架构 + 聪明数据 = 强效果。

核心贡献

  1. 视觉指令微调 — 首次将 instruction tuning 扩展到多模态
  2. 数据生成流程 — 用 GPT-4 生成 150K 高质量图文对话
  3. 简洁架构 — CLIP + LLM + 简单投影层
  4. 全开源 — 模型、数据、代码全部公开

模型架构

┌─────────────────┐
│     Image       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  CLIP ViT-L/14  │  冻结，提取视觉特征
│  (Vision Encoder)│  输出: 576 tokens (24×24)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Linear/MLP     │  可训练，对齐视觉-语言
│  Projection     │  将视觉 token 投影到 LLM 空间
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────┐
│        Vicuna / LLaMA           │
│  [视觉tokens] [文本tokens]       │
│       ↓                         │
│   Autoregressive Generation     │
└─────────────────────────────────┘

关键设计

  • 视觉编码器： CLIP ViT-L/14 (冻结)
  • 投影层： 简单的线性层 or 2 层 MLP
  • 语言模型： Vicuna-7B/13B (指令微调的 LLaMA)

训练流程

Stage 1: 预训练（对齐）

数据: CC-595K (图像-caption 对)
训练: 只训练投影层，冻结 Vision Encoder 和 LLM
目标: 学习视觉-语言对齐

Stage 2: 指令微调

数据: LLaVA-Instruct-150K (GPT-4 生成)
训练: 训练投影层 + LLM (LoRA 或全量)
目标: 学习遵循视觉指令

数据生成（精华！）

用 GPT-4 生成训练数据

输入给 GPT-4:
- 图像的 caption
- 图像的 bounding boxes（来自目标检测）
- 任务类型（对话/详细描述/复杂推理）

GPT-4 输出:
- 多轮对话
- 基于视觉内容的问答

三种数据类型

类型 数量 示例
Conversation 58K Q: 图里有什么动物? A: 一只橙色的猫...
Detail Description 23K 详细描述这张图片的所有元素...
Complex Reasoning 77K 为什么这个人看起来很开心?

输入格式

# 系统提示
System: A chat between a user and an AI assistant...

# 用户输入（包含图像）
Human: <image>
What is unusual about this image?

# 模型回复
Assistant: The unusual thing about this image is...

其中 <image> 会被替换为 576 个视觉 token。

实验结果

Science QA（多选题）

模型 准确率
GPT-4 (text only) 67.3%
LLaVA 90.9%
LLaVA + GPT-4 判断 92.5%

GPT-4 评估（相对分数）

在对话、详细描述、复杂推理任务上，LLaVA 达到 GPT-4 85%+ 的水平。

代码示例

# 使用 transformers
from transformers import LlavaProcessor, LlavaForConditionalGeneration
from PIL import Image

model_id = "llava-hf/llava-1.5-7b-hf"
processor = LlavaProcessor.from_pretrained(model_id)
model = LlavaForConditionalGeneration.from_pretrained(model_id)

image = Image.open("example.jpg")
prompt = "USER: <image>\nWhat is shown in this image?\nASSISTANT:"

inputs = processor(text=prompt, images=image, return_tensors="pt")
output = model.generate(**inputs, max_new_tokens=100)
print(processor.decode(output[0], skip_special_tokens=True))

LLaVA 1.5 改进

  • MLP Projection — 2 层 MLP 替代线性层
  • 更高分辨率 — 336×336 输入
  • 更多数据 — 665K 预训练 + 665K 微调
  • 学术任务数据 — 加入 VQA、OCR 等数据

个人思考

LLaVA 的成功说明：数据质量 > 模型复杂度。相比 Q-Former 这样的复杂设计，LLaVA 用简单的线性投影 + 高质量 GPT-4 生成数据，取得了更好的效果。这启发我们：在 VLM 领域，投资数据可能比投资架构更划算。
