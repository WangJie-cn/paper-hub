🔄 Self-Attention, Cross-Attention 与自回归详解

类型: 架构笔记 | 主题: Transformer 核心机制

📊 Self-Attention vs Cross-Attention

Self-Attention Cross-Attention
Q, K, V 来源 全部来自同一序列 Q 来自一个序列，K/V 来自另一个
作用 序列内部建模 跨模态/序列融合
典型应用 BERT、GPT encoder VLM 图文融合、机器翻译

🔵 Self-Attention（自注意力）

核心思想

序列中的每个位置都去"看"序列中的所有其他位置，计算它们的相关性。

输入序列 X = ["我", "爱", "北京"]

              Q(Query)    K(Key)     V(Value)
                ↓           ↓           ↓
"我"    →    q₁ ───────→ 与所有 k 计算相似度 → 加权求和 v → 输出 y₁
"爱"    →    q₂ ───────→ 与所有 k 计算相似度 → 加权求和 v → 输出 y₂
"北京"  →    q₃ ───────→ 与所有 k 计算相似度 → 加权求和 v → 输出 y₃

┌────────────────────────────────────────────────────────┐
│  Self-Attention: Q, K, V 都来自同一个序列 X            │
│                                                        │
│  Q = X @ W_Q                                           │
│  K = X @ W_K    ← 同一个 X！                           │
│  V = X @ W_V                                           │
│                                                        │
│  Attention(Q, K, V) = softmax(QKᵀ/√d) × V             │
└────────────────────────────────────────────────────────┘

代码示例

def self_attention(x, W_q, W_k, W_v):
    """
    x: 输入序列 (seq_len, d_model)
    """
    Q = x @ W_q  # Query 来自 x
    K = x @ W_k  # Key 来自 x
    V = x @ W_v  # Value 来自 x
    
    scores = Q @ K.T / sqrt(d_k)
    weights = softmax(scores, dim=-1)
    output = weights @ V
    
    return output

🟢 Cross-Attention（交叉注意力）

核心思想

一个序列（比如文本）去"查询"另一个序列（比如图像），实现跨模态信息融合。

图像特征: Image = [img₁, img₂, ..., img₁₉₆]  (196 个 patch)
文本序列: Text = ["Describe", "this", "image"]

Cross-Attention:
              Q(来自Text)   K,V(来自Image)
                  ↓              ↓
"Describe" →    q₁ ─────────→ 与所有 img_k 计算相似度
                              → 找到最相关的图像区域
                              → 加权求和 img_v
                              → 输出融合后的特征

┌────────────────────────────────────────────────────────┐
│  Cross-Attention: Q 来自序列 A，K/V 来自序列 B         │
│                                                        │
│  Q = Text @ W_Q    ← 来自文本                          │
│  K = Image @ W_K   ← 来自图像                          │
│  V = Image @ W_V   ← 来自图像                          │
│                                                        │
│  Attention(Q, K, V) = softmax(QKᵀ/√d) × V             │
│                                                        │
│  效果：文本的每个 token 都能"看到"整张图像              │
└────────────────────────────────────────────────────────┘

代码示例

def cross_attention(text_features, image_features, W_q, W_k, W_v):
    """
    text_features: 文本序列 (text_len, d_model)
    image_features: 图像特征 (num_patches, d_model)
    """
    Q = text_features @ W_q   # Query 来自文本
    K = image_features @ W_k  # Key 来自图像
    V = image_features @ W_v  # Value 来自图像
    
    # 文本的每个 token 都去图像中"查询"
    scores = Q @ K.T / sqrt(d_k)  # (text_len, num_patches)
    weights = softmax(scores, dim=-1)
    output = weights @ V  # (text_len, d_model)
    
    return output  # 融合了视觉信息的文本特征

🔁 自回归（Autoregressive）

什么是自回归？

生成序列时，一个一个 token 地生成，每次生成都依赖于之前已生成的所有 token。

┌────────────────────────────────────────────────────────────┐
│                    自回归生成过程                           │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Step 1: 输入 "What is"                                    │
│          → 模型预测下一个词 → "the"                         │
│                                                            │
│  Step 2: 输入 "What is the"                                │
│          → 模型预测下一个词 → "capital"                     │
│                                                            │
│  Step 3: 输入 "What is the capital"                        │
│          → 模型预测下一个词 → "of"                          │
│                                                            │
│  Step 4: 输入 "What is the capital of"                     │
│          → 模型预测下一个词 → "France"                      │
│                                                            │
│  Step 5: 输入 "What is the capital of France"              │
│          → 模型预测下一个词 → "?"                           │
│                                                            │
│  ✅ 最终输出: "What is the capital of France?"             │
│                                                            │
└────────────────────────────────────────────────────────────┘

数学表示:
P(x₁, x₂, ..., xₙ) = P(x₁) × P(x₂|x₁) × P(x₃|x₁,x₂) × ...

每个 token 的概率都依赖于之前所有 token！

Causal Mask（因果掩码）

为了实现自回归，需要用 mask 防止"偷看"未来的 token：

# Causal Mask 示例 (4 个 token)
#      t₁  t₂  t₃  t₄
# t₁ [  1   0   0   0 ]  ← t₁ 只能看 t₁
# t₂ [  1   1   0   0 ]  ← t₂ 能看 t₁, t₂
# t₃ [  1   1   1   0 ]  ← t₃ 能看 t₁, t₂, t₃
# t₄ [  1   1   1   1 ]  ← t₄ 能看所有

mask = torch.tril(torch.ones(seq_len, seq_len))
# 下三角矩阵：1 表示可以看到，0 表示不能看到

🤔 LLM 和 VLM 中的应用

LLM（如 GPT）

  • ✅ 使用 Self-Attention + Causal Mask（自回归）
  • ✅ 文本生成是自回归的
  • ❌ 不使用 Cross-Attention（纯文本模型）

VLM（如 LLaVA）

  • ✅ 图像编码器：Self-Attention（ViT）
  • ✅ 文本解码器：Self-Attention + Causal Mask（自回归生成）
  • ✅ 图文融合：Cross-Attention 或 直接拼接
  • ✅ 文本输出是自回归的

轨迹预测（如 π0）

  • ❌ 通常不是自回归
  • ✅ 使用 Flow Matching 或 Diffusion
  • ✅ 一次性生成整条轨迹，不是一步一步
任务 是否自回归 原因
LLM 文本生成 ✅ 是 语言天然是序列的
VLM 文本输出 ✅ 是 同上
图像生成 ❌/✅ Diffusion 不是，PixelCNN 是
轨迹预测 ❌ 通常不是 需要全局规划，非逐步
机器翻译 ✅ 是 Decoder 自回归生成
