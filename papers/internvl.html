🔮 InternVL: Scaling up Vision Foundation Models

arxiv: 2312.14238 | 作者: 上海AI Lab (书生团队) | 年份: 2023

一句话总结

6B 参数的视觉基础模型，在 图像分类、检测、分割、VLM 等任务上全面刷榜，证明视觉模型也能 scale up。

核心贡献

  1. InternViT-6B — 最大的开源视觉 Transformer
  2. QLLaMA — 跨模态对齐的 LLM
  3. 渐进式训练 — 对比学习 → 生成式学习
  4. 全任务 SOTA — 18 个视觉-语言 benchmark 最优

训练策略

Stage 1: 对比学习

数据: 大规模图文对 (类似 CLIP)
目标: 学习视觉-语言对齐
Loss: InfoNCE

Stage 2: 生成式学习

数据: 图文对话、VQA、Caption
目标: 学习视觉理解和生成
Loss: Next Token Prediction

渐进式扩展

ViT-H (600M) → InternViT-2B → InternViT-6B
逐步扩大模型，继承小模型的参数

代码示例

from transformers import AutoModel, AutoTokenizer

model = AutoModel.from_pretrained(
    "OpenGVLab/InternVL-Chat-V1-5",
    trust_remote_code=True
).cuda()
tokenizer = AutoTokenizer.from_pretrained(
    "OpenGVLab/InternVL-Chat-V1-5",
    trust_remote_code=True
)

# 推理
response = model.chat(
    tokenizer,
    pixel_values=image,
    question="描述这张图片"
)
print(response)

个人思考

InternVL 证明了视觉模型也遵循 scaling law。6B 的视觉编码器比 CLIP 的 400M 强太多。这暗示未来 VLM 的瓶颈可能不再是 LLM，而是视觉编码器。
