🧩 Backbone/Head vs Multi-Head Attention 详解

类型: 架构笔记 | 主题: 深度学习架构中的"Head"概念辨析

⚠️ 先说结论

Backbone + Head 和 Multi-Head Attention 是完全不同的概念！
它们只是恰好都用了 "Head" 这个词，但含义截然不同。

📊 概念对比

Backbone + Head Multi-Head Attention
层级 模型架构层面 单个模块内部
作用 功能分工 并行计算多种注意力
"Head"含义 任务输出头 注意力的并行分支
数量 通常 1-5 个 通常 8/12/16 个
参数 各自独立训练 共享输入，分割维度

🏗️ Part 1: Backbone + Head 架构

什么是 Backbone？

Backbone（骨干网络）是模型的特征提取器，负责将原始输入转换为高级特征表示。

常见的 Head 类型

Head 类型 任务 输出 典型结构
Classification Head 图像分类 类别概率 Global Pool + FC + Softmax
Detection Head 目标检测 bbox + 类别 FPN + RPN / DETR decoder
Segmentation Head 语义分割 像素 mask 上采样 + 1x1 Conv
LM Head 语言建模 下一个 token Linear(hidden, vocab_size)
Regression Head 回归任务 连续值 FC layers

代码示例

import torch.nn as nn
from torchvision.models import resnet50

class MultiTaskModel(nn.Module):
    def __init__(self):
        super().__init__()
        
        # Backbone: 提取通用特征
        backbone = resnet50(pretrained=True)
        self.backbone = nn.Sequential(*list(backbone.children())[:-2])  # 去掉最后的池化和FC
        
        # Head 1: 分类
        self.cls_head = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(2048, 1000)
        )
        
        # Head 2: 检测 (简化版)
        self.det_head = nn.Conv2d(2048, 4 + 80, 1)  # 4个bbox坐标 + 80类
        
    def forward(self, x):
        # 共享 backbone
        features = self.backbone(x)  # (B, 2048, H/32, W/32)
        
        # 各自的 head
        cls_out = self.cls_head(features)
        det_out = self.det_head(features)
        
        return cls_out, det_out

🎯 Part 2: Multi-Head Attention

什么是 Multi-Head Attention？

Multi-Head Attention 是 Transformer 内部的一个注意力计算模块，通过并行运行多个注意力"头"来捕获不同类型的依赖关系。

┌─────────────────────────────────────────────────────────────────┐
│               Multi-Head Attention 内部结构                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   输入: X ∈ R^(seq_len × d_model)                               │
│         例如 d_model = 768                                       │
│                                                                 │
│            │                                                    │
│            ▼                                                    │
│   ┌─────────────────────────────────────────────────────┐      │
│   │  线性投影: 生成 Q, K, V                              │      │
│   │  Q = X @ W_Q    (768 → 768)                         │      │
│   │  K = X @ W_K    (768 → 768)                         │      │
│   │  V = X @ W_V    (768 → 768)                         │      │
│   └──────────────────────┬──────────────────────────────┘      │
│                          │                                      │
│          ┌───────────────┼───────────────┐                      │
│          │      分割成 h 个头 (h=12)      │                      │
│          │   每个头: 768/12 = 64 维       │                      │
│          │                               │                      │
│   ┌──────┴──────┐ ┌──────┴──────┐ ┌──────┴──────┐              │
│   │   Head 1    │ │   Head 2    │ │   Head 12   │              │
│   │             │ │             │ │             │              │
│   │  Q₁ K₁ V₁   │ │  Q₂ K₂ V₂   │ │ Q₁₂ K₁₂ V₁₂│  ...         │
│   │  (64 dim)   │ │  (64 dim)   │ │  (64 dim)   │              │
│   │             │ │             │ │             │              │
│   │ Attention₁  │ │ Attention₂  │ │ Attention₁₂ │              │
│   │  = softmax  │ │  = softmax  │ │  = softmax  │              │
│   │  (Q₁K₁ᵀ/√d) │ │  (Q₂K₂ᵀ/√d) │ │  (Q₁₂K₁₂ᵀ/√d)             │
│   │    × V₁     │ │    × V₂     │ │    × V₁₂   │              │
│   │             │ │             │ │             │              │
│   │  输出: 64   │ │  输出: 64   │ │  输出: 64   │              │
│   └──────┬──────┘ └──────┬──────┘ └──────┬──────┘              │
│          │               │               │                      │
│          └───────────────┼───────────────┘                      │
│                          │ Concat                               │
│                          ▼                                      │
│                 ┌─────────────────┐                             │
│                 │  Concat + Linear │                            │
│                 │  (768 → 768)     │                            │
│                 └────────┬────────┘                             │
│                          │                                      │
│                          ▼                                      │
│   输出: Y ∈ R^(seq_len × d_model)                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

为什么要 Multi-Head？

  • 不同的注意力模式 — 有的 head 关注局部，有的关注全局
  • 不同的特征子空间 — 64 维 × 12 个 head = 768 维
  • 提高表达能力 — 单个 head 只能学一种注意力模式

代码示例

import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=768, n_heads=12):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads  # 每个 head 的维度
        
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
        
    def forward(self, x):
        B, L, D = x.shape
        
        # 线性投影
        Q = self.W_q(x)  # (B, L, 768)
        K = self.W_k(x)
        V = self.W_v(x)
        
        # 分割成多个 head
        # (B, L, 768) → (B, L, 12, 64) → (B, 12, L, 64)
        Q = Q.view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(B, L, self.n_heads, self.d_k).transpose(1, 2)
        
        # 每个 head 独立计算 attention
        # (B, 12, L, 64) @ (B, 12, 64, L) → (B, 12, L, L)
        attn_scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
        attn_weights = F.softmax(attn_scores, dim=-1)
        
        # (B, 12, L, L) @ (B, 12, L, 64) → (B, 12, L, 64)
        out = attn_weights @ V
        
        # 合并所有 head
        # (B, 12, L, 64) → (B, L, 12, 64) → (B, L, 768)
        out = out.transpose(1, 2).contiguous().view(B, L, D)
        
        return self.W_o(out)

🔑 关键区别:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Multi-Head Attention 的 "Head": 
  → 在 Transformer 层内部
  → 并行计算不同的注意力模式
  → 数量: 8/12/16 个
  → 维度分割: d_model / n_heads

• Task Head (任务头): 
  → 在 Backbone 之后
  → 针对特定任务的输出层
  → 数量: 1-5 个
  → 独立的网络模块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎭 总结表格

特性 Backbone + Task Head Multi-Head Attention
出现位置 模型最外层结构 Transformer 层内部
设计目的 功能解耦、多任务学习 捕获多种注意力模式
Head 数量 等于任务数（1-5） 固定超参数（8/12/16）
维度 各 Head 独立维度 d_model / n_heads
参数共享 共享 Backbone 共享 W_q, W_k, W_v
输出合并 不合并，各自输出 Concat + Linear
例子 ResNet + FC, ViT + Det Head BERT 的 12 个 attention head

💡 直观类比

Backbone + Head 像一个公司：
- Backbone = 研发部门（提供基础技术）
- Classification Head = 产品部（做消费品）
- Detection Head = 安防部（做监控系统）
- 共享研发，各自输出产品 Multi-Head Attention 像一个团队开会：
- 每个 Head = 一个角度的讨论
- Head 1 关注"谁说了什么"
- Head 2 关注"说的顺序"
- Head 3 关注"说话的语气"
- 最后把所有角度的信息综合起来
