🧠 Self-Attention vs Cross-Attention

1️⃣ 两种 Attention 对比

Self-AttentionCross-Attention
Q 来源自己模态 A（如文本）
K, V 来源自己模态 B（如图像）
作用序列内部建模跨模态融合
例子GPT/ViT 内部VLM 图文融合

2️⃣ Cross-Attention 核心公式

Q = 文本特征 × Wq   ← Query 来自"想查询的一方"
K = 图像特征 × Wk   ← Key 来自"被查询的一方"
V = 图像特征 × Wv   ← Value 来自"被查询的一方"

Attention = softmax(Q × KT / √d) × V

3️⃣ 具体例子：VLM 理解图片

图像特征 (来自 ViT): ┌─────┬─────┬─────┬─────┐ │ 🚗车 │ 👤人 │ 🔴灯 │ 🛣️路 │ ← 4 个图像 patch 特征 → K, V └─────┴─────┴─────┴─────┘ 文本 Query: "图中有什么车？" ┌─────┬─────┬─────┬─────┬─────┐ │ 图 │ 中 │ 有 │ 什么 │ 车 │ ← 5 个 text token → Q └─────┴─────┴─────┴─────┴─────┘ Cross-Attention 计算: "车" 这个 Q 会和所有图像 K 计算相似度 → 发现和 "🚗车" patch 最相似 (权重 0.8) → 重点关注 "车" 的 V 特征

4️⃣ 代码实现

class CrossAttention(nn.Module):
    def __init__(self, dim):
        self.q_proj = nn.Linear(dim, dim)  # 文本 → Q
        self.k_proj = nn.Linear(dim, dim)  # 图像 → K
        self.v_proj = nn.Linear(dim, dim)  # 图像 → V
    
    def forward(self, text_features, image_features):
        Q = self.q_proj(text_features)   # [batch, text_len, dim]
        K = self.k_proj(image_features)  # [batch, img_patches, dim]
        V = self.v_proj(image_features)  # [batch, img_patches, dim]
        
        # 注意力权重：文本的每个token对图像每个patch的关注度
        attn = torch.softmax(Q @ K.transpose(-1,-2) / sqrt(dim), dim=-1)
        
        # 加权求和：文本token获取相关的图像信息
        out = attn @ V  # [batch, text_len, dim]
        return out

5️⃣ 关键理解

  • Self-Attention：序列内部的 token 互相关注，建模上下文关系
  • Cross-Attention：让一个模态（文本）去"查询"另一个模态（图像）的相关信息
  • Q 决定"问什么"，K 决定"有什么可以被查"，V 是"实际返回的信息"
  • 在 VLM 中，Cross-Attention 是实现 图文融合 的核心机制
